# Casa Contreras 3D

Protótipo navegável em primeira pessoa do projeto Casa Contreras.

- Terreno-base: 10,00 x 25,00 m
- Envelope da casa: 6,058 x 7,076 m
- Navegação: WASD + mouse, Shift para correr, Espaço para pular
- Clique esquerdo: seleciona elementos e abre feedback
- Feedbacks são enviados como GitHub Issues com metadados do objeto selecionado

## Estado

MVP 0.1 — estrutura inicial do tour 3D e sistema de feedback.
